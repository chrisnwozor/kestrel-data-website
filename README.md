# Kestrel Data

Website for Kestrel Data, a data cleanup and reporting service for small businesses in London, Ontario.

**Every detail, seen clearly.**

## Services

- **Data Cleanup**: sales exports, spreadsheets and supplier lists combined into one accurate dataset
- **Business Dashboard**: a custom dashboard for revenue, best sellers, slow periods and waste
- **Monthly Reporting**: data cleaned, dashboard refreshed and a plain-English summary every month

## Tech

A single static page (HTML and CSS, no framework), hosted on Netlify. The contact form uses Netlify Forms.
